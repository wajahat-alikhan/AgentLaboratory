# جائزہ
* ایجنٹ لیبارٹری ایک اختتام سے اختتام تک خود مختار تحقیق کا نظام ہے جو آپ کو، بطور انسان محقق، تحقیقاتی خیالات کے نفاذ میں مدد فراہم کرتا ہے۔ ایجنٹ لیبارٹری مخصوص ایجنٹس پر مشتمل ہے جو بڑے زبان ماڈلز کے ذریعے چلائے جاتے ہیں اور مکمل تحقیقی عمل میں آپ کا ساتھ دیتے ہیں، جیسے کہ تحقیقاتی مواد کا جائزہ لینا، منصوبے بنانا، تجربات کرنا، اور مکمل رپورٹس تیار کرنا۔
* یہ نظام آپ کی تخلیقی صلاحیت کو ختم کرنے کے لیے نہیں بنایا گیا بلکہ اسے بڑھانے کے لیے بنایا گیا ہے، تاکہ آپ اپنے خیالات اور تنقیدی سوچ پر توجہ مرکوز کر سکیں، جبکہ کوڈنگ اور ڈاکیومینٹیشن جیسے وقت طلب اور دہرائے جانے والے کام خودکار طور پر انجام دیے جا سکیں۔ مختلف کمپیوٹیشنل وسائل اور انسانی شمولیت کی سطحوں کو مدنظر رکھتے ہوئے، ایجنٹ لیبارٹری کا مقصد سائنسی دریافت میں تیزی لانا اور آپ کی تحقیقی کارکردگی کو بہتر بنانا ہے۔

# 🔬 ایجنٹ لیبارٹری کیسے کام کرتا ہے؟
* ایجنٹ لیبارٹری تحقیقی عمل کو تین بنیادی مراحل میں منظم کرتا ہے:
1. تحقیقی مواد کا جائزہ
2. تجربات
3. رپورٹ تحریر
   
ہر مرحلے میں، مخصوص ایجنٹس (LLMs کے ذریعے چلائے جانے والے) مختلف کاموں کو مکمل کرنے کے لیے مل کر کام کرتے ہیں۔ یہ نظام بیرونی ٹولز جیسے کہ arXiv، Hugging Face، Python، اور LaTeX کے ساتھ انضمام کرتا ہے تاکہ نتائج کو بہتر بنایا جا سکے۔ یہ عمل متعلقہ تحقیقاتی مقالوں کے خود مختار جمع کرنے اور تجزیے سے شروع ہوتا ہے، منصوبہ بندی اور ڈیٹا کی تیاری کے ذریعے آگے بڑھتا ہے، اور خودکار تجربات اور مکمل رپورٹ کی تیاری پر اختتام پذیر ہوتا ہے۔
# 👾 حالیہ طور پر معاون ماڈلز
* OpenAI: o1, o1-preview, o1-mini, gpt-4o
* DeepSeek: deepseek-chat (deepseek-v3)

کسی خاص ماڈل کو منتخب کرنے کے لیے، درج ذیل فلیگ استعمال کریں: --llm-backend="llm_model"
مثال کے طور پر: --llm-backend="gpt-4o" یا --llm-backend="deepseek-chat"
