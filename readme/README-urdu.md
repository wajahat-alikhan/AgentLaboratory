# جائزہ
* ایجنٹ لیبارٹری ایک اختتام سے اختتام تک خود مختار تحقیق کا نظام ہے جو آپ کو، بطور انسان محقق، تحقیقاتی خیالات کے نفاذ میں مدد فراہم کرتا ہے۔ ایجنٹ لیبارٹری مخصوص ایجنٹس پر مشتمل ہے جو بڑے زبان ماڈلز کے ذریعے چلائے جاتے ہیں اور مکمل تحقیقی عمل میں آپ کا ساتھ دیتے ہیں، جیسے کہ تحقیقاتی مواد کا جائزہ لینا، منصوبے بنانا، تجربات کرنا، اور مکمل رپورٹس تیار کرنا۔
* یہ نظام آپ کی تخلیقی صلاحیت کو ختم کرنے کے لیے نہیں بنایا گیا بلکہ اسے بڑھانے کے لیے بنایا گیا ہے، تاکہ آپ اپنے خیالات اور تنقیدی سوچ پر توجہ مرکوز کر سکیں، جبکہ کوڈنگ اور ڈاکیومینٹیشن جیسے وقت طلب اور دہرائے جانے والے کام خودکار طور پر انجام دیے جا سکیں۔ مختلف کمپیوٹیشنل وسائل اور انسانی شمولیت کی سطحوں کو مدنظر رکھتے ہوئے، ایجنٹ لیبارٹری کا مقصد سائنسی دریافت میں تیزی لانا اور آپ کی تحقیقی کارکردگی کو بہتر بنانا ہے۔
